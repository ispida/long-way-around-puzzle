# `content/themes/default/`

Complete fallback theme: must contain a picture for every tile, piece and actor (CI checks this), and every word key used in content and UI texts.

Story cast (also used by **Brown bear**): bees save honey from the bear; pieces are logs (a stack of logs), the score counts jars saved, the hive's bees chase the bear. Story word keys: `animal`, `Animal`, `food`, `Food`, `pot`, `unit`, `units`, `guardians`, `Guardians`, `piece`, `pieces`, `Piece`, `bonus`, plus tile names `mud`, `burrow`, `hive`, `slope`.
