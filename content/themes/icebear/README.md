# `content/themes/icebear/`

"Ice bear" theme: puffins save fish from the ice bear, in the Arctic. A complete set of its own pictures (extends `default` only for anything new): snow ground, small icebergs instead of trees, the sea with an ice floe, deep-snow drifts, ice slides, ice holes as portals, a walrus colony instead of the beehive, ice-brick walls as pieces and a bucket of fish. Words: fish, ice walls, walruses, Deep snow, Ice slides, Iceberg, Sea. Board frame: icy blue.
